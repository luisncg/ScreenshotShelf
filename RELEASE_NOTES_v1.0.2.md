# Screenshot Shelf v1.0.2

Preview polish release.

## What's changed

- Click any screenshot thumbnail to open a larger preview.
- Large previews now animate in instead of popping onto the screen.
- Hovering a thumbnail shows a centered preview affordance.
- Copy buttons briefly show a green copied checkmark.
