# Screenshot Shelf

Screenshot Shelf keeps Mac screenshots off the Desktop and puts recent captures in the menu bar.

## Features

- Saves new screenshots directly to Screenshot Shelf instead of the Desktop
- Shows a small preview when a screenshot is captured
- Copy a screenshot or drag it into another app
- Open the full shelf from the menu bar
- Import older Desktop screenshots when needed
- Checks for updates automatically

## Install

1. Download the latest `ScreenshotShelf.dmg` from Releases.
2. Open the DMG.
3. Drag Screenshot Shelf into Applications.
4. Launch Screenshot Shelf from Applications.

Screenshot Shelf is signed and notarized for macOS.
